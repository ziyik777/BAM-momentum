# BAM MOMENTUM Website

This is a complete static website for the BAM MOMENTUM internship project.

## Files
- `index.html` — website structure/content
- `style.css` — visual design
- `script.js` — navigation + mood-board popups
- `assets/` — mood boards and design sketches

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload **all files and the `assets` folder**.
3. Make sure `index.html` is in the top level of the repository.
4. Go to **Settings → Pages**.
5. Under the build/source option, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save. GitHub will give you a public website address.

You do not need a framework, npm, or a paid hosting service.
